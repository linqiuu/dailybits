# 整改与验证记录

日期：2026-10-13，Asia/Shanghai。

## 本次整改

- 统一题库页面、题目、评论和订阅的内容可见性判断；部门使用稳定 Directory ID；群订阅仅面向公开内容，由订阅创建者或管理员管理。
- Auth Hub 旧身份升级事务迁移所有个人 targetId 和外键；身份唯一字段冲突时拒绝自动合并。
- 调度改为 PostgreSQL 持久化任务，独立题目、知识、摘要消费者；支持补发窗口、租约恢复、顺序领取、快照、有限重试和回执后本地补记。
- 生产推送缺少配置不再模拟成功；发送结果不确定时暂停自动补发；保留订阅历史，独立统计新一轮题库进度。
- 卡片服务增加 QA 请求幂等预留和答题递增游标；回调和定时补拉共用答案幂等落库。
- 总览计入三类订阅，答题按完整上海自然日统计；展示趋势、排行、运行状态和失败信息。
- 页面取消发光背景及嵌套面板，采用紧凑卡片与平面内容区；改善暗色对比度、知识阅读、错误重试、权限状态和键盘操作；创建内容支持真实分页。
- 推送预览读取真实缓存并复用发送格式化器，不再显示虚构示例或不可用操作。
- PG 默认不映射端口；密码必填且自动编码数据库 URL；增加健康检查、回环 Web 绑定和可选本地 PG 映射。

## 验证结果

- 主项目 72 项测试通过，包括实际 PostgreSQL 集成测试与 Inner API 4010 Mock 联调。
- TypeScript、ESLint、生产构建、Debian Bookworm Docker 镜像构建通过。
- 独立 Compose 栈完整启动：16 个 Prisma 迁移成功，Web/PG 健康，Scheduler 正常启动，PG 无宿主机端口。
- card-service 44 项测试及 Ruff 通过，包括请求重放、内容冲突、处理中和结果不确定时避免再次创建卡片、答案去重及游标分页。
- Playwright 检查 1440px/1280px 桌面窗口，覆盖发现、我的内容、管理员、创建、详情、编辑、群组和预览，另检查暗色模式及失败状态。
- 实际验证私有/部门访问、草稿隐藏、群订阅归属、回调密钥、当日统计范围、预览翻页、创建内容翻页及知识库重新订阅。
- 页面无横向溢出、无未命名的空按钮、无浏览器脚本错误。

所有集成测试使用独立临时 PostgreSQL、SQLite 和合成用户/内容；未修改原有数据库，未向真实用户发送卡片。测试产物保留在被 Git 忽略的 `browser-artifacts/verification/`。

## 上线边界

- 先部署新版 card-service，再迁移并启用 DailyBits Scheduler；导入旧数据时保持 Scheduler 停止。
- 必须配置真实服务地址、密钥、稳定管理员 ID、网关来源限制和精确机器回调豁免。正式 Auth Hub/IM/模型凭据未在本机进行真实联调。
- Messaging 幂等键由 Inner API 透传，严格去重取决于公司消息上游；Mock 不保证重放时相同 messageId。本项目不承诺跨所有上游 exactly-once。
- 补发限于配置窗口内；旧部门名称需重新选择稳定 ID；身份字段冲突需人工核对。
- 部署及迁库步骤见 [Docker Compose 部署](deployment-docker-compose.md)。
